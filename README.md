# POWERPASS – אפליקציית אנדרואיד

אפליקציית מובייל לסימולטור מבחני הרישוי בחשמל של [www.powerpass.co.il](https://www.powerpass.co.il).
הבנייה מתבצעת ב-**Capacitor 8**, וה-APK החתום נבנה בענן ב-**GitHub Actions**. לא צריך להתקין שום סביבת פיתוח במחשב.

> **דרישה מוקדמת:** תוסף הוורדפרס בגרסה **3.22.0 ומעלה** מותקן באתר (הקובץ `moe-quiz-simulator-v3_22_0.zip`).

---

## מה יש באפליקציה

| יכולת | איך זה עובד |
|---|---|
| התחברות עם אותו חשבון של האתר | `POST /app/login`. עובר את כל בדיקות האתר: חסימת IP, חשבון מושעה ואימות מייל |
| מכשיר אחד בכל רגע | התחברות באפליקציה מנתקת את המחשב, והתחברות במחשב מנתקת את האפליקציה. זה אותו מנגנון של האתר, כולל מעקב המכשירים היומי |
| תרגול אופליין עד 7 ימים | המאגר נשמר במכשיר מוצפן ב-AES-256-GCM. המפתח האישי נמסר רק למנוי פעיל. כל חיבור לרשת מחדש את 7 הימים |
| כל סוגי הסימולציות של האתר | מבחן מלא, 10 שאלות מהירות, תשובות מיידיות, לפי נושא, לפי מספרים, שמורות, טעויות, למהנדסים בלבד |
| מנוע הסימולציה של האתר | `www/js/vendor/quiz.js` הוא העתק של הקובץ מהתוסף, ללא שינוי: אותה חוויה, אותם שרטוטים והגדלה, אותה שמירת מיקום |
| סנכרון אוטומטי | תוצאות, סטטיסטיקה, שאלות שמורות ודיווחים שנאספו אופליין נשלחים כשחוזר חיבור, בלי כפילויות |
| חסימת צילומי מסך | `FLAG_SECURE` ברמת אנדרואיד. גם המסך במצב "אפליקציות אחרונות" מוצג ריק |
| סימן מים | סימן מים עדין עם שם ואימייל המשתמש בכל מסך |
| רכישה | כפתור שפותח את עמוד המסלולים באתר כשהמשתמש כבר מחובר. התשלום ב-Smartbee/MAX והחתימה על התקנון נעשים באתר כרגיל |
| מצב חנות (`STORE_MODE`) | מסתיר את כל קישורי הרכישה והמחירים (Reader App), לקראת Google Play / App Store |
| מצב כהה | אוטומטי לפי הטלפון, או בחירה ידנית |

## מה חדש בגרסה 1.1.0 – מחשבונים

- **לשונית "מחשבונים" חדשה** בסרגל התחתון.
- **14 המחשבונים הרגילים** פתוחים לכל משתמש מחובר, גם בלי מנוי.
- **הכלים המתקדמים** (מחולל שרטוט חד קווי, ערך LT, מפל מתח ועמדת טעינה, התאמת מבטח לכבל, עלות חשמל) פתוחים למנוי פעיל בלבד. הבדיקה היא אותו רישיון של הסימולציות, ולכן עובדת גם אופליין עד 7 ימים. למי שאין מנוי הם מוצגים נעולים, עם כפתור למסלולים (מוסתר ב-`STORE_MODE`).
- **הכול רץ במכשיר, בלי אינטרנט.** קובצי המחשבונים ב-`www/js/vendor` הם העתק של קובצי התוסף (`calc.js`, `calc-pro-lib.js`, `calc-pro.js`, `oneline.js`), ולכן התוצאות זהות לאתר.
- **שמירה ושיתוף מהמחולל:** תמונה, SVG וקובץ פרויקט נפתחים בחלון השיתוף של אנדרואיד (שמירה ל-Drive או לקבצים, וואטסאפ, מייל, הדפסה מהתמונה). לשם כך נוספו `@capacitor/filesystem` ו-`@capacitor/share` (מותקנים אוטומטית בבנייה).
- **כלי שסגרת באתר** (במצב "סגור" בהגדרות "גישה לכלים מתקדמים") לא מוצג גם באפליקציה, ותעריף החשמל נלקח מהאתר. זה דורש תוסף בגרסה **3.22.13 ומעלה** (נתיב `/app/tools`). בלי העדכון האפליקציה עובדת כרגיל עם ברירות המחדל.
- כשמעדכנים את המחשבונים בתוסף, מעתיקים את ארבעת הקבצים שלמעלה ל-`www/js/vendor`, ואת `calc-pro.css` ו-`oneline.css` ל-`www/css`.

## שלב 0 – עדכון התוסף באתר

1. בלוח הבקרה של וורדפרס: **תוספים ← הוספת תוסף ← העלאת תוסף**. בוחרים את `moe-quiz-simulator-v3_22_0.zip` ומאשרים החלפה.
2. בודקים שה-API עובד. פותחים בדפדפן את הכתובת:
   `https://www.powerpass.co.il/wp-json/moeqs/v1/app/settings`
   אמור להופיע טקסט JSON שמתחיל ב-`{"plugin":"3.22.0"...`.
3. אם יש באתר תוסף אבטחה (Wordfence וכד') או Cloudflare, מוודאים שהם לא חוסמים את `/wp-json/moeqs/v1/app/`.

## שלב 1 – העלאת הפרויקט ל-GitHub

1. נכנסים ל-[github.com](https://github.com) ויוצרים מאגר חדש: **New repository**, בשם למשל `powerpass-app`, ובוחרים **Private**.
2. במאגר הריק לוחצים **uploading an existing file**, וגוררים פנימה את **כל התוכן** של התיקייה `powerpass-app` (לא את התיקייה עצמה).
3. **חשוב:** מוודאים שגם התיקייה הנסתרת `.github` עלתה. אחרי ההעלאה אמורה להופיע במאגר התיקייה `.github/workflows` עם שני קבצים. במק התיקייה נסתרת ב-Finder: לוחצים `Cmd+Shift+.` כדי להציג אותה. אפשרות נוחה יותר היא [GitHub Desktop](https://desktop.github.com).
4. לוחצים **Commit changes**.

## שלב 2 – מפתח חתימה (Keystore) וסודות ב-GitHub

כל עדכון של האפליקציה **חייב** להיחתם באותו מפתח. אם המפתח אובד, משתמשים שכבר התקינו לא יוכלו לקבל עדכונים, ויצטרכו למחוק את האפליקציה ולהתקין אותה מחדש.

### 2א. הוספת שלושה סודות

במאגר: **Settings ← Secrets and variables ← Actions ← New repository secret**. מוסיפים:

| שם הסוד (בדיוק כך) | מה לשים |
|---|---|
| `ANDROID_KEYSTORE_PASSWORD` | סיסמה חזקה (16+ תווים, אותיות ומספרים) |
| `ANDROID_KEY_ALIAS` | `powerpass` |
| `ANDROID_KEY_PASSWORD` | אותה סיסמה כמו `ANDROID_KEYSTORE_PASSWORD` (מומלץ) |

> שמרו את הסיסמה גם במנהל סיסמאות. GitHub לא מאפשר לראות סוד אחרי שנשמר.

### 2ב. יצירת ה-Keystore בענן (פעם אחת בלבד)

1. לשונית **Actions** ← בצד: **Create signing keystore (one-time)** ← **Run workflow**.
2. בשדה מקלידים `YES` ולוחצים **Run workflow**.
3. כשההרצה מסתיימת (✓ ירוק), נכנסים אליה ומורידים מתחתית העמוד את **powerpass-keystore-DELETE-AFTER-DOWNLOAD**.
4. בקובץ שהורד יש שלושה קבצים:
   - `powerpass-release.jks`: **המפתח עצמו**. שומרים אותו בגיבוי בטוח, לתמיד (מנהל סיסמאות, דיסק חיצוני).
   - `keystore-base64.txt`: פותחים בעורך טקסט ומעתיקים את **כל** התוכן.
   - `fingerprint.txt`: טביעת האצבע של המפתח, לתיעוד.
5. מוסיפים סוד רביעי: **`ANDROID_KEYSTORE_BASE64`** ומדביקים בו את התוכן של `keystore-base64.txt`.
6. חוזרים לעמוד ההרצה ומוחקים את ה-Artifact (סמל הפח), כדי שהמפתח לא יישאר שם.

<details>
<summary>אפשרות חלופית: יצירה במחשב (למי שיש Java)</summary>

```bash
keytool -genkeypair -v -keystore powerpass-release.jks -storetype JKS \
  -alias powerpass -keyalg RSA -keysize 4096 -validity 10950 \
  -dname "CN=POWERPASS, O=Oded Electric, L=Rishon LeZion, C=IL"
# macOS / Linux:
base64 -i powerpass-release.jks | tr -d '\n' > keystore-base64.txt
# Windows (PowerShell):
[Convert]::ToBase64String([IO.File]::ReadAllBytes("powerpass-release.jks")) > keystore-base64.txt
```
</details>

## שלב 3 – בניית ה-APK בלחיצת כפתור

1. לשונית **Actions** ← **Build Android APK** ← **Run workflow**.
2. אפשרויות:
   - **build_type**: `release` (חתום, להפצה). `debug` מתאים לבדיקה ראשונה מהירה ולא דורש Keystore.
   - **store_mode**: להשאיר כבוי בהפצת APK ישירה.
   - **api_base**: להשאיר ריק. אפשר להזין כתובת של אתר בדיקות, למשל `https://staging.powerpass.co.il/wp-json/moeqs/v1`.
3. לוחצים **Run workflow** ומחכים 8–15 דקות. ההרצה הראשונה איטית יותר.
4. נכנסים להרצה שהסתיימה. בתחתית העמוד, תחת **Artifacts**, מורידים את **POWERPASS-apk**. זה ZIP, ובתוכו `POWERPASS-v1.0.0-<מספר>.apk`.

**גרסה חדשה:** משנים את `"version"` בקובץ `package.json` (למשל ל-`1.0.1`) ומריצים שוב. מספר הגרסה הפנימי (versionCode) עולה אוטומטית בכל הרצה.
**שחרור עם עמוד הורדה:** יוצרים תגית `v1.0.1` (Releases ← Draft a new release), וה-APK יצורף אוטומטית ל-Release.

## שלב 4 – התקנה בטלפון אנדרואיד

1. מעבירים את קובץ ה-APK לטלפון (וואטסאפ לעצמכם, מייל, Google Drive).
2. פותחים את הקובץ בטלפון. בפעם הראשונה אנדרואיד מבקש לאשר **"התקנה מאפליקציות לא מוכרות"** עבור האפליקציה שממנה פתחתם (Chrome / Files). מאשרים.
3. לוחצים **התקנה**.

> **אימות מפתחים של Google:** בהדרגה, ובישראל לפי ההודעות הנוכחיות ב-2027, אנדרואיד ידרוש שאפליקציות שמותקנות מקובץ יגיעו ממפתח מאומת. מומלץ לרשום מראש את העוסק ב-[Android Developer Console](https://support.google.com/android-developer-console/answer/16561738) ולרשום את טביעת האצבע מ-`fingerprint.txt`.

## בדיקות מומלצות במכשיר

- [ ] התחברות עם משתמש מנוי. המאגר והשרטוטים יורדים פעם אחת (כ-12MB, עדיף ב-Wi-Fi).
- [ ] התחברות לאותו משתמש באתר מהמחשב. האפליקציה מקבלת "התנתקת מהמערכת". ולהפך: התחברות באפליקציה מנתקת את המחשב תוך 15 שניות.
- [ ] מצב טיסה, ואז מבחן מלא, הגשה, וביומן מופיע "ממתין לסנכרון". מכבים את מצב הטיסה, והתוצאה מופיעה גם ביומן באתר.
- [ ] צילום מסך באפליקציה נחסם (מופיעה הודעה או תמונה שחורה).
- [ ] משתמש בלי מנוי: מופיע "אין מנוי פעיל". "למסלולי המנוי" פותח את עמוד המסלולים באתר כשהמשתמש כבר מחובר. אחרי התשלום חוזרים לאפליקציה, והמנוי מתעדכן.
- [ ] כפתור "חזרה" של אנדרואיד, מצב כהה, הגדלת שרטוט בצביטה.

## נקודות הקצה בתוסף (3.22.0)

כל הנתיבים תחת `https://www.powerpass.co.il/wp-json/moeqs/v1`:

| נתיב | שיטה | הרשאה | תפקיד |
|---|---|---|---|
| `/app/login` | POST | – | התחברות. מחזיר אסימונים, פרטי משתמש ורישיון |
| `/app/refresh` | POST | Refresh token | חידוש אסימון הגישה (אסימון חדש בכל פעם) |
| `/app/logout` | POST | Bearer | התנתקות. מוחק את ההתחברות בשרת |
| `/app/me` | GET | Bearer | משתמש, מנוי, השהיה, רישיון אופליין (מפתח + תוקף) |
| `/app/bank/manifest` | GET | Bearer | גרסת המאגר ורשימת השרטוטים |
| `/app/bank` | GET | Bearer + מנוי | המאגר המוצפן (AES-256-GCM) |
| `/app/settings` | GET | – | הגדרות האתר: זמנים, ציון עובר, צבעים, קישורים, מועדי בחינה |
| `/app/history` | GET / POST | Bearer | יומן, סטטיסטיקה, שמורות. POST מסנכרן את מה שנאסף אופליין |
| `/app/plans` | GET | – | מסלולי המנוי (לתצוגה) |
| `/app/handoff` | POST / GET | Bearer / קישור חד-פעמי | פתיחת האתר בדפדפן כשהמשתמש כבר מחובר (רכישה / חשבון) |

גם נקודות הקצה הקיימות שבודקות `is_user_logged_in()`, כמו `/report` ו-`/reset`, עובדות מהאפליקציה בלי שינוי.

## פתרון בעיות

| תסמין | פתרון |
|---|---|
| ה-Workflow נכשל: "חסר הסוד ANDROID_KEYSTORE_BASE64" | לא הושלם שלב 2. לבדיקה מהירה אפשר להריץ עם `build_type = debug` |
| ההתחברות באפליקציה מחזירה כל הזמן "ההתחברות אינה תקפה" | האחסון או תוסף אבטחה מסירים כותרות. האפליקציה שולחת גם `X-PowerPass-Token`, אבל צריך לוודא ש-WAF / Cloudflare לא חוסמים את `/wp-json/moeqs/v1/app/` |
| "השרת לא תומך בהצפנת AES-256-GCM" | צריך לבקש מחברת האחסון להפעיל את הרחבת OpenSSL ב-PHP (כמעט תמיד פעילה) |
| המאגר לא מתעדכן אחרי עריכת שאלה | האפליקציה בודקת גרסה בכל סנכרון. אפשר ללחוץ על כפתור הסנכרון בכותרת |
| "התקנה נחסמה" בטלפון | צריך לאשר "התקנה מאפליקציות לא מוכרות" (שלב 4) |
| עדכון לא מותקן מעל גרסה קודמת | ה-APK נחתם במפתח אחר. משתמשים תמיד באותו `ANDROID_KEYSTORE_BASE64` (וגרסת debug תמיד חתומה במפתח אחר) |

## מבנה הפרויקט

```
powerpass-app/
├── www/                     # האפליקציה (HTML/CSS/JS, בלי שלב build)
│   ├── index.html           # מסך ראשי: התחברות, בית, סימולציות, יומן, חשבון, מסלולים
│   ├── quiz.html            # מסך הסימולציה
│   ├── js/config.js         # API_BASE, STORE_MODE, גרסה
│   ├── js/core.js           # תקשורת, התחברות, רישיון אופליין, הצפנה, IndexedDB, סנכרון
│   ├── js/app.js            # ממשק המסך הראשי
│   ├── js/quiz-boot.js      # בניית הסימולציה מהמאגר המקומי (כמו moeqs_request_config)
│   ├── js/vendor/quiz.js    # מנוע הסימולציה של התוסף, ללא שינוי
│   └── css/                 # app.css + quiz.css + גופן Assistant
├── android-res/             # אייקונים ומסך פתיחה
├── scripts/                 # copy-cap / configure / patch-android / check
├── capacitor.config.json    # il.co.powerpass.app · POWERPASS
└── .github/workflows/       # build-apk.yml · create-keystore.yml
```

**מה נשמר בטלפון:** אסימוני התחברות, פרטי המשתמש, מפתח הרישיון האופליין, המאגר **המוצפן** (IndexedDB), השרטוטים, ופעולות שממתינות לסנכרון. בהתנתקות, בניתוק ממכשיר אחר או כשהמנוי מסתיים, המפתח והמאגר נמחקים. הגיבוי של אנדרואיד כבוי לאפליקציה (`allowBackup=false`).

**מגבלה שחשוב להכיר:** תרגול אופליין מחייב שהמפתח יישמר בטלפון. אנדרואיד מגן עליו באמצעות בידוד האפליקציות, אבל בטלפון פרוץ (root), משתמש עם ידע טכני יכול לחלץ אותו. ההגנות שמגבילות את הנזק: מפתח אישי לכל התחברות, מחיקה בניתוק, תוקף של 7 ימים, חסימת צילומי מסך וסימן מים מזהה.
